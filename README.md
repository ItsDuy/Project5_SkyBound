## Game Overview

**SkyBound** is an action-packed 3D platformer shooting game where players navigate floating islands, battle enemies, and complete objectives. The game offers two modes:
- **Single Player Mode**: Play solo and conquer challenges on your own.
- **Multiplayer Mode**: Team up or compete with friends in an online environment.

The game combines fast-paced shooting mechanics with platforming elements, requiring precision, strategy, and quick reflexes.

---

## Features

- **Two Game Modes**: Single-player campaign and multiplayer battles.
- **Dynamic Gameplay**: Navigate floating platforms while engaging in intense combat.
- **Customizable Characters**: Choose and customize your character's appearance and loadout.
- **Varied Environments**: Explore diverse levels with unique themes and challenges.
- **Power-Ups and Weapons**: Collect power-ups and unlock new weapons to gain an edge over your enemies.
- **Multiplayer Matchmaking**: Seamless matchmaking for competitive or cooperative play.
- **Godot 4.5 Powered**: Built using the latest version of the Godot Engine for stunning visuals and smooth performance.

## Installation

### Prerequisites
- Download and install [Godot Engine 4.5](https://godotengine.org/download).
- Ensure your system meets the minimum requirements for running Godot 4.5.

### Steps
1. Clone or download the SkyBound repository:
   ```bash
   git clone https://github.com/yourusername/SkyBound.git
   ```
2. Open the project in Godot 4.5:
   - Launch Godot Engine.
   - Click on "Import" and select the `project.godot` file from the downloaded folder.
3. Run the game:
   - Select the main scene (`Main.tscn`) and click the "Play" button.

## Controls

### General Controls
- **W/A/S/D**: Move character.
- **Spacebar**: Jump.
- **Mouse Movement**: Aim.
- **Left Mouse Button**: Shoot.
- **Esc**: Pause menu.
